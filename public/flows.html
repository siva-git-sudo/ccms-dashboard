Where cases moved between logins

2026-08-11 to 2026-08-13 · 47 cases changed hands across 15 movements

CCMS gives no case numbers, so a file cannot be followed directly. But a case only leaves a login's books by being handed to another login, and it keeps its stage when it moves. Matching each day's senders to that day's receivers, stage by stage, reconstructs the handovers. Where one login sent and one login received the same number of cases at the same stage on the same day, the link is certain. Where several did, the pairing is inferred.

None of this is work. Every case below stayed at exactly the same stage — it only changed desk. Counted login by login, a handover reads as progress for whoever received it and as a reversal for whoever sent it.
