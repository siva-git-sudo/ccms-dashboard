## Longer version — email

**Subject: CCMS court case dashboard — daily position, all courts in one view**

Dear Sir / Madam,

Following up on the difficulty we all face in reading the pending case
position across courts, I have built a dashboard on top of the public
CCMS "Outside Secretariat" report:

**https://siva-git-sudo.github.io/ccms-dashboard/**

No login, no installation. It opens in any browser and is designed to be
read on a phone as well as a desktop.

**What it shows**

The full Forest, Ecology and Environment position before the High Court
of Karnataka and the Karnataka State Administrative Tribunal — 96 units
across all 13 circles and Aranya Bhavana HQ, down to 225 individual
officer records. As on 12 August 2026 this is 2,775 cases pending.

**Where it helps over the CCMS report itself**

1. *One view instead of eight.* CCMS returns one report per court and
   case type. Getting a division's true total means running eight
   reports and adding them up. The dashboard does that once, daily.

2. *Movement, not just position.* CCMS shows where things stand today.
   The dashboard keeps a daily snapshot, so every figure — statewide,
   division, wing, officer, and individual stage — carries the change
   against the previous day. Weekly and monthly comparisons will become
   available as the archive builds up.

3. *Whose desk the case is on.* The seventeen stages are grouped into
   Stalled, Departmental, Advocate, Court, Post order and Completed. A
   division with forty cases in Departmental has a very different problem
   from one with forty awaiting hearing, and that distinction is not
   visible in a row of seventeen numbers.

4. *Usable on a phone.* The CCMS report is a wide table that does not
   survive a mobile screen. The dashboard shows the same data as cards
   that expand on tap.

5. *Filters that carry their own counts.* Circle, division, wing, court,
   case type and stage — each filter shows what it will return before
   you click it.

**Please note**

The dashboard is a read-only view of CCMS data. It does not replace
CCMS, and CCMS remains the official record. The figures are extracted as
published, so if any number looks wrong for your division, please tell me
and I will verify the extraction.

Suggestions on what else would be useful to see are very welcome.

Regards,

Sivasankar S
